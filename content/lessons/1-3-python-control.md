## 1. if：满足条件，才走这条路

:::flow 程序走哪条路
- 输入一本书的年份。
- 问：年份是否至少2020？
- 若是，写“新书”；若不是，写“较早出版”。
- 显示分类结果。
:::

```python
year = 2021
if year >= 2020:
    label = "新书"
else:
    label = "较早出版"
print(label)
```

输入第三本书的年份2021，条件产生 True，执行 `if` 下面的赋值，不执行 `else` 的赋值。实际输出“新书”。把输入改成2016重新运行，结果是“较早出版”。每次只走一条分支，print 没有缩进，所以不论哪条分支都执行。

`if` 后面跟判断和英文冒号；下一行空四格表示属于这条分支。`else` 意思是“否则”，后面也要冒号，它与 `if` 左边对齐。Jupyter 通常会在冒号后自动缩进，按退格可回到左边。缩进是代码结构，不是为了好看；不要一行四个空格、一行随意两个空格。

```python
price = 88.9
if price < 50:
    price_label = "低于50元"
elif price <= 80:
    price_label = "50至80元"
else:
    price_label = "高于80元"
print(price_label)
```

输入第一本书价。`elif` 表示“前一个条件不满足，再问这个条件”。88.9既不小于50，也不小于等于80，实际输出“高于80元”。50会进入第二档，80也进入第二档，边界必须写清。按从上到下顺序遇到第一个真条件后停止选分支，不会把几个标签都写进去。

:::compare 等号和缩进
:::bad 条件写成 `if year = 2020:`
一个等号是赋值，不能在这里代替判断；会有 SyntaxError。把这个错误当说明看，不要放进可执行格。
:::
:::good 条件写成 `if year == 2020:`
两个等号比较是否恰好2020；若题目问“至少2020”，应写 `>=`。修语法后仍要核对题意。
:::
:::

## 2. for：列表每一项，做同一件事

```python
titles = ["月光与我", "雨夜的孩子", "故园往事"]
for title in titles:
    print(title)
```

输入三项列表。`for title in titles` 可以读成“每次从 titles 取一个值，临时叫它 title”。循环执行三次，依次输出三本书名。`title` 是循环中单本书的名字，`titles` 是整个列表，起不同名字能减少混淆。不要先手写 `title = titles[0]` 再复制三次；列表长度改变时，循环会按当前项数执行。

现在做求和，拆成“起点”和“每次累加”两部分。

```python
prices = [88.9, 36.9, 80.5]
total = 0
for price in prices:
    total = total + price
print(total)
```

输入三本价格。先设合计为0；第一次变成88.9，第二次变成125.8，第三次变成206.3，最后输出206.3。`total = total + price` 的右边读旧合计，左边保存新合计。print 在循环外，只输出最后结果。如果把 `total = 0` 缩进到循环里，每次都会归零，最后只剩最后一本80.5。

:::df 跟踪循环，不凭感觉猜
| 次数 | 本次price | 累加前total | 累加后total |
|---:|---:|---:|---:|
| 1 | 88.9 | 0 | 88.9 |
| 2 | 36.9 | 88.9 | 125.8 |
| 3 | 80.5 | 125.8 | 206.3 |
:::

## 3. 循环里判断：筛一份短书单

一本书有多个字段，用上一课学过的字典；三本书放进列表。这里先显式写清楚，暂时不用列表推导式、lambda 或其他缩写。

```python
book_list = [
    {"title": "月光与我", "price": 88.9},
    {"title": "雨夜的孩子", "price": 36.9},
    {"title": "故园往事", "price": 80.5},
]
cheap_titles = []
for book in book_list:
    if book["price"] <= 50:
        cheap_titles.append(book["title"])
print(cheap_titles)
```

输入三条图书资料。先创建空结果列表；每次取一本，问价格是否不超过50；满足才追加书名。实际输出 `['雨夜的孩子']`。这里有两层缩进：if 属于循环，append 属于条件。空列表放在循环前，否则每轮都会抹掉之前的结果。

两层结构看不懂时，用手指跟踪一条记录：第一本不满足，不追加；第二本满足，追加；第三本不满足，保留现有结果。循环结束后列表可能有0项、1项或多项，都合理。不要把输出一个书名就误解成字符串，外层方括号说明仍是列表。

## 4. 函数：把同一个公式装进可重复调用的小工具

你已经会计算 `单价 × 数量 × (1 - 减免比例)`。换一笔订单，如果每次复制公式，容易有一行忘记扣折扣。函数 `function` 给这段操作一个名字，输入换了，公式仍统一。

```python
def discounted_total(unit_price, quantity, discount):
    amount = unit_price * quantity * (1 - discount)
    return amount
```

这里没有输出。`def` 定义函数；名字后括号里的三个名字叫参数，相当于预留三个输入位置。`return` 把算好的值交给调用者，而不是直接显示在屏幕。先运行定义格，后面才能使用这个函数。当前只是三行公式，不需要学类、装饰器或复杂工具。

```python
first_amount = discounted_total(12.0, 2, 0.0)
promo_amount = discounted_total(22.0, 5, 0.1)
print(first_amount)
print(promo_amount)
```

输入第一笔订单的单价12、数量2、无折扣，以及SG25000039的22、5、0.1。函数分别算出24.0和99.0，再由print显示。顺序与参数一一对应；把数量和折扣对调，即使代码能运行也会算错。0.1仍是减10%，不是一折。

:::warn print 和 return 不替代彼此
函数里只写 `print(amount)` 会显示一个数，但调用结果通常是 None，后面不能继续当金额用。`return` 给出可保存、可运算的结果；要显示，调用者再print。函数定义中的 amount 是函数内部的临时名字，本课不让你在外部直接读取它。
:::

- [x] 循环开始前，作为累计起点

:::try 1-3.3 循环筛选
遍历准备好的 `first_books`，把价格不超过50元的书名追加到 result 列表，保持原顺序。

```python
result = []
for book in first_books:

```
输入三本资料，仅第二本满足，得到 `['雨夜的孩子']`。
:::

:::try 1-3.4 封装折后金额
写 `discounted_total(unit_price, quantity, discount)`，用 return 返回金额。把函数本身赋给 result：`result = discounted_total`，此处不加调用括号。检查会拿多笔随包订单试算，不能只返回99。
:::
:::fold 答案与观察
```python
def discounted_total(unit_price, quantity, discount):
    return unit_price * quantity * (1 - discount)
result = discounted_total
```
输入参数在调用时才给。检查会验证无折扣和有折扣订单，确认函数能够复用，不只是记住一个答案。
:::

## 报错与纠正路径

| 错误 | 排查动作 |
|---|---|
| IndentationError | 看冒号下一行有没有缩进；同层是否对齐 |
| NameError | 先运行函数定义与数据准备格，核对名字 |
| TypeError: 缺少参数 | 调用时是否传入单价、数量、折扣三个输入 |
| 返回None | 检查有没有return，是否误用print代替 |
| 合计只有最后一个值 | 初始化是否误放进循环；print位置是否正确 |
