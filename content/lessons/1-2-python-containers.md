## 1. 列表：把多个值按顺序排队

如果每本书都起一个名字 `title1`、`title2`、`title3`，书多了会忙乱。列表 `list` 是一个按顺序放值的容器，用英文方括号 `[]`，项与项之间用英文逗号。这里“顺序”是你写入的先后，不代表评分或销量排序。

```python
titles = ["月光与我", "雨夜的孩子", "故园往事"]
print(titles)
print(len(titles))
```

输入前三本书名，第一行创建列表并命名；`len` 问“这里有几项”。实际输出：

```output
['月光与我', '雨夜的孩子', '故园往事']
3
```

输出用单引号，不影响你输入用双引号。一个列表可以容纳数字，例子 `prices = [88.9, 36.9, 80.5]`；也可以混合类型，但本课建议同一列表存同一种信息，减少混淆。列表的外层方括号不是书名文字的一部分。

:::df 列表位置示意：这是数组位置，不是图书编号
| 从左往右的位置（索引） | 值 | 从右往左的位置 |
|---:|---|---:|
| 0 | 月光与我 | -3 |
| 1 | 雨夜的孩子 | -2 |
| 2 | 故园往事 | -1 |
:::

## 2. 索引从 0 开始，不是从 1 开始

```python
print(titles[0])
print(titles[1])
print(titles[-1])
```

输入已创建的 `titles`，分别取第一个、第二个、最后一个值。输出为“月光与我”“雨夜的孩子”“故园往事”。索引 `index` 在这里就是位置编号。`[1]` 不是第一本；`[-1]` 不是“负数的书”，而是从右边数的第一项。名字后的一对方括号现在表示“从已有列表取东西”，而等号右边的独立方括号表示“创建列表”，要结合位置看。

```python
try:
    print(titles[3])
except IndexError:
    print("只有3项，可用的正向索引是0、1、2。")
```

输入三项列表，却索要第四项。会触发 `IndexError`；示范把错误捕获后输出中文，不会中断“运行全部”。本课先认识提示，不要求你背 `try/except`；遇到自己代码出错时，数一下项数并改索引即可。对空列表取 `[-1]` 也会越界，负数位置并不是万能保险。

## 3. 切片：取一段，不是取一个

```python
print(titles[0:2])
print(titles[:2])
print(titles[1:])
```

输入同一列表。`[0:2]` 从位置 0 开始，到位置 2 之前停止，所以第一行得到 `['月光与我', '雨夜的孩子']`，共两项。省略起点默认从开头，第二行结果相同；省略终点走到末尾，第三行得到 `['雨夜的孩子', '故园往事']`。冒号让它成为切片，结果仍是列表。

:::compare 取值和取片段
:::bad 把 `titles[0]` 当成一个列表
它实际是书名字符串“月光与我”。你取出的是单个元素，不再带列表外壳。
:::
:::good 用 `titles[0:1]` 保留列表
它实际是 `['月光与我']`，里面只有一项。取第一项和取“只含第一项的列表”，是两个不同需求。
:::
:::

切片超过末尾通常只取已有项，不一定报错。所以没有报错不代表范围正确：`titles[:10]` 仍只有三项。做报告要检查数量，不要把“成功运行”和“筛选对了”画等号。pandas 的标签选取有不同规则，到第 2-2 课会专门提醒，不能把这一条机械套到所有表格。

## 4. 添加一项：append 不等于重新赋值

```python
reading_list = ["月光与我", "雨夜的孩子"]
reading_list.append("故园往事")
print(reading_list)
```

输入两本书的候选清单，`.append(...)` 的意思是“在这个列表末尾追加一项”。点号把操作接到列表上。输出三本书，前两项顺序不变。这是直接修改 `reading_list`，不需要再写 `reading_list = reading_list.append(...)`；那样会把名字改成该操作返回的 None，而不是新列表。

本课不要求你熟练删除或复杂复制，先掌握创建、取项、切片、追加。不要随手在准备好的原始列表上加内容然后忘记执行过几次。一个追加格重复运行，可能把同一本书加两遍。上面的格子把初始化也放在一起，每次都会从两本重新开始，便于复现。

## 5. 字典：一项资料，用键给每个字段命名

列表回答“第几项”，字典 `dict` 回答“哪个字段”。一本书同时有书名、价格和品类，用一组“键:值”更清楚。外层用英文花括号 `{}`，键通常是字符串，键和值之间用冒号，不是等号。

```python
book = {"title": "月光与我", "price": 88.9, "category": "历史"}
print(book["title"])
print(book["price"] * 2)
```

输入第一本书的三个字段。`book["title"]` 按键取书名，输出“月光与我”；`book["price"]` 取出数字后乘 2，输出 177.8。不要写 `book[0]` 去取“第一项”：这里没有数字 0 这个键。`price` 和 `"price"` 也不一样，前者找变量，后者是字段名文字。

```python
book["price"] = 90.0
print(book["price"])
```

输入现有字典，把价格键对应的值替换为 90.0，输出 90.0。这个例子只改变内存中的教学字典，不写回原始 `books.csv`；CSV 第一行仍是 88.9。正式分析应保留原始文件，修改后的变量最好起新名字。

:::warn 字典的键不能代表两条不同记录
同一个字典里键要唯一。`{"price": 88.9, "price": 36.9}` 最后只保留后一个价格，不会保存两本书。多本书以后可放进表格；本课不要靠重复字段名硬装进去。
:::

```python
try:
    print(book["Price"])
except KeyError:
    print("没有Price这个键；已有键是title、price、category。")
```

输入大小写写错的键，会发生 `KeyError`，捕获后显示中文。检查字段拼写和两侧空格，是处理表格也会用到的习惯。没有这个键不意味着价格为 0，别为了消除错误随意补一个数字。

:::quiz
`titles = ["月光与我", "雨夜的孩子", "故园往事"]`，`titles[0:2]` 有几项？
- [ ] 3项，因为终点2也被包含
- [x] 2项，因为取位置0、1，不包含2
- [ ] 1项，因为索引从0开始
---
Python 列表切片左包含、右不包含；`titles[2]` 才是单独取位置2的值。
:::

## 排错与求职迁移

| 错误或现象 | 先检查 | 不要这样“修” |
|---|---|---|
| IndexError | 项数、索引是否从0起 | 反复重启却不改越界位置 |
| KeyError | 键大小写、引号、空格 | 把缺失字段直接当0 |
| SyntaxError | 花括号与方括号、逗号与冒号 | 把中文标点混进代码 |
| 追加后列表成了 None | 是否把 append 的返回值赋回去 | 把 None 当成列表继续索引 |

:::job 文科经验可以迁移
整理书目、采访提纲、活动物料清单，都是“多个条目”；一条资料的“名称、价格、分类”是有标签的字段。面试解释 list 和 dict 时，用这一差别比背英文定义更清楚。真正处理 200 本书时会用 DataFrame，不会让你手工写 200 行字典。
:::
