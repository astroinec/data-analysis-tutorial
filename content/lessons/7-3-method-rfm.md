## 1. 什么是 RFM 模型？

给所有客户发同一张满减券往往既浪费预算、又打扰老客。**RFM 模型**只用订单表里最常见的三个行为指标，就能把客户清清楚楚分成不同价值层级：

:::cards RFM 三个维度
:::card R · Recency（最近一次消费距今）
`基准日 - 最后一次已完成下单时间`（天数）。**R 越小越好**：昨天刚买过的客户比半年前买过的客户活跃得多。
:::
:::card F · Frequency（消费频次）
观察窗口内的唯一已完成订单数。**F 越大越好**：代表客户粘性与复购习惯。
:::
:::card M · Monetary（消费金额）
观察窗口内的已完成实付金额总和。**M 越大越好**：代表客户对店铺的营收贡献。
:::
:::

在文创店 2427 位购买客户中，三项指标的中位数实测为：**R = 50 天、F = 3 单、M = 376.20 元**。为什么用**中位数**而不是均值做切分阈值？因为我们在 [5-1 描述统计](lesson:5-1) 学过，消费金额与频次明显右偏，均值会被极少数土豪客户拉高，导致大量活跃客户被误判为“低价值”。

## 2. 八类客户分层与对应运营动作

规定：`R_high = (R <= 50)`、`F_high = (F >= 3)`、`M_high = (M >= 376.2)`，组合出 8 类客户：

:::df RFM 八类分层定义与运营思路
| R（近不近） | F（频不频） | M（高不高） | 分层名称 | 建议运营动作（待验证假设） |
|---|---|---|---|---|
| 高（近） | 高 | 高 | **重要价值客户** | VIP 专属服务、新品优先体验、切忌过度打折伤品牌 |
| 低（远） | 高 | 高 | **重要保持客户** | 曾经高频高额但近期沉默，定向提醒/回访防流失 |
| 高（近） | 低 | 高 | **重要发展客户** | 刚买过且客单高但频次低，推送关联商品促复购 |
| 低（远） | 低 | 高 | **重要挽留客户** | 大额一次性客户即将流失，用有针对性的召回券测试 |
| 高/低 | 高/低 | 低 | 一般价值/保持/发展/挽留 | 低成本自动化触达为主，控制营销投入产出比 |
:::

实测结果呈现出鲜明的**二八效应**：**重要价值客户仅 756 人（占购买客户的 31.15%），却贡献了 1,247,488.80 元（占总已完成净销售额的 69.91%）**！

## 3. RFM 模型的适用边界

RFM 很好用，但绝不是万能钥匙：
- **不适合低频耐用品**（如买房、买车、大型家电）：几年才买一次，F 几乎全是 1。
- **不适合冷启动新客**：刚注册未下单的 573 位客户没有 R/F/M，需要用注册渠道与浏览行为做新客激活。
- **不包含利润与退货率**：高 M 但高退款率的客户并不等于高利润客户。

:::quiz RFM 方向判断
基准日为 2026-01-01。客户 A 的 `R = 5 天`，客户 B 的 `R = 180 天`，整体中位数 `R_med = 50 天`。谁属于“R 高（近期活跃）”？
- [ ] 客户 B，因为 180 > 50
- [x] 客户 A，因为 R 是距今天数，天数越小说明消费越近、越活跃
- [ ] 两人都不算
---
R 是反向指标（越小越好），代码里务必写成 `R <= R_med`，千万别顺手写成 `R >= R_med`。
:::

## 4. 四道独立练习

:::try 7-3.1 计算每位购买客户的 R、F、M 原始值
以 `2026-01-01` 为基准日，对已完成订单按 `customer_id` 输出 `customer_id, R, F, M`，按 `customer_id` 升序。
:::fold 参考答案
```python
done_ex = orders.loc[orders["status"].eq("已完成")]
rfm_ex = done_ex.groupby("customer_id", as_index=False).agg(
    last_time=("order_time", "max"), F=("order_id", "nunique"), M=("pay_amount", "sum"))
rfm_ex["R"] = (pd.Timestamp("2026-01-01") - rfm_ex["last_time"]).dt.days
ans_7_3_1 = rfm_ex[["customer_id", "R", "F", "M"]].sort_values("customer_id").reset_index(drop=True)
```
:::

## 常见问题与求职用途

| 问题 | 纠正路径 |
|---|---|
| 把 `R >= R_med` 当成高价值 | R 是距今天数，越小越近，必须 `R <= R_med` |
| 用 `customers.csv` 全部 3000 人算 RFM | 573 位未成交客户没有消费记录，应明确只对 2427 位购买客户分层，其余单列“注册未购池” |
| 忘记过滤退款订单 | 退款订单不应计入 F 和 M |
