## 模拟数据来源与边界

本包模拟数据由 `generate_data.py` 使用固定随机种子2025制作。人物、商品、书名和交易记录均虚构，适合练代码和检查口径，不适合推断真实店铺、市场或消费者。生成器显式设置季节、活动、平台退款概率与客户倾向；这些结构不是观察真实世界所得的因果证据。固定随机种子便于同版本包对照，不应把它理解为所有不同软件版本、未来修改脚本都必然逐字节相同。

模拟文件的生成来源已明确，但整份教程的再发布权利应看包的授权说明；不要因为“我能运行脚本”就替维护者发明开放许可证。独立作品中必须注明“模拟教学数据”，不写真实企业经营表现。

### orders.csv：2025订单全集

| 字段 | 白话含义与单位 | 分析规则 |
|---|---|---|
| order_id | 唯一订单编号，文本 | 每行一单一种商品，先验证唯一 |
| order_time | 下单时间，YYYY-MM-DD HH:MM:SS | 全在2025；无退款时间 |
| customer_id | 客户编号 | 连customers，多订单同客户正常 |
| product_id | 商品编号 | 连products，一单一种商品 |
| quantity | 该商品购买件数 | 正整数，不是订单数 |
| unit_price | 下单时每件标价，元 | 与实付价格不同 |
| discount | 折扣比例，0～1 | 0.1=减10%，支付90% |
| pay_amount | 订单原支付，元 | 单价×件数×(1-折扣)，按分取整；退款行仍保留原支付 |
| platform | 淘宝、微信小程序、抖音小店 | 下单平台，不是客户来源channel |
| status | 已完成或已退款 | 已退款按全额退款，净销售额只纳入已完成 |
| rating | 模拟1～5评分 | 当前6969行缺失，多为未评价；不填0不删交易 |

当前15115笔订单中13996笔已完成、1119笔已退款。项目只将已完成支付之和1784371.10元称“已完成净销售额”业务口径，不称财务确认收入。全状态原支付GMV为1928401元，包含已退款原支付144029.90元。完整口径见[项目课](lesson:P-1)。

### orders_dirty.csv与orders_gbk.csv：故意弄脏的练习表

### tips.csv：244笔账单，不是全部餐厅客人

| 字段 | 含义 |
|---|---|
| total_bill | 账单总金额，美元 |
| tip | 小费，美元 |
| sex | 记录中的付款者性别分类 |
| smoker | 同桌是否有吸烟者的分类记录 |
| day | 星期标签Thur/Fri/Sat/Sun，不是具体日期 |

当前无缺失字段。一行一笔账单；`size` 不是CSV行数。可研究账单与小费的关联，不把单一历史样本推断为所有餐厅，更不能把相关性当“多花钱一定导致多给小费”。小费率=tip/total_bill，不是tip/size。

## 取数与授权的实际工作习惯

在工作里优先使用已获授权的导出，不在网页上爬个人电话、住址或账号等隐私，不把企业订单上传到第三方工具寻求“快速分析”。公开作品尽量保留汇总而非原始个体记录，并写出来源、日期、许可证核实状态、是否改编。模拟数据不存在真实客户隐私，但仍需模拟声明，以免读者把图误认为真实证据。
