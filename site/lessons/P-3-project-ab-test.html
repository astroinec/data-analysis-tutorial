P-3项目三：A/B 测试分析

用虚构的 12,000 人商品详情页新版评价卡片实验，走完 SRM 校验、主指标检验、护栏指标评估、新老客异质性拆解与上线决策。

  • 约 150 分钟
  • 难度 ★★★
  • 配套练习本 notebooks/P-3_project_ab_test.ipynb
  • 前置：已完成阶段 5（尤其是第 5-4 课），会用 scipy 做卡方与 Welch t 检验

本项目的可检验目标

  • 独立完成 A/B 测试五步标准流程：质量体检 → SRM 分流校验 → 总体主/辅助/护栏指标检验 → 人群异质性拆解 → 业务决策。
  • 用卡方拟合优度检验确认分流未发生 SRM（样本比例失衡）。
  • 分别用卡方检验与 Welch t 检验评估转化率、页面加载耗时与已转化客单价。
  • 发现“增益集中在首次访问新客、老客无显著变化，且加载耗时增加约 43.5ms”的核心权衡，给出可执行建议。
  • 通过练习本 P-3.1 ～ P-3.6 六道自动检查。

本项目基于虚构的“商品详情页新版评价卡片”14 天 A/B 测试数据（data/abtest/ab_experiment.csv，12,000 名用户，50/50 随机分流）。数据由程序模拟生成，仅用于学习严谨的实验分析流程，不代表真实业务上线收益。

请在本包 notebooks/P-3_project_ab_test.ipynb 打开练习本，内核选 Python (da-course)；参考答案在 solutions/。

  1. 明确实验假设与指标体系（主指标 / 辅助指标 / 护栏指标）
  2. 数据体检与 SRM 校验（分流不准，后面全作废）
  3. 总体主指标与辅助指标显著性检验
  4. 护栏指标（页面加载耗时）副作用评估
  5. 分新老客、分设备异质性拆解 → 形成灰度/上线决策

第一步：指标体系设计与数据体检

指标层级 指标名称 定义 期望方向
主指标（OEC） 下单转化率 conv_rate converted 均值 显著上升
辅助指标 详情互动点击率 / 人均 GMV（ARPU） / 已转化客单价 clicked 均值 / order_amount 均值 / 已转化者 order_amount 均值 上升或持平
护栏指标 页面加载耗时 page_load_ms 详情页平均加载毫秒数 不出现不可接受的恶化

数据体检确认：user_id 12,000 行完全唯一；每名转化用户均有点击记录（converted <= clicked）；未转化用户 order_amount 均为 0。

第二步：SRM（样本比例失衡）校验（P-3.1）

实验设计为 50/50 分流。实际分到对照组 5,976 人、实验组 6,024 人。调用 stats.chisquare([5976, 6024]) 得 chi2 = 0.1920，p = 0.6613 >> 0.01，通过 SRM 校验，说明分流比例无显著偏斜，可以继续分析。

第三步：总体指标与护栏指标评估（P-3.2 ～ P-3.4）

分组 人数 点击率 转化率 人均 GMV (ARPU) 平均加载耗时
control（旧版） 5,976 32.70% 8.75% 6.77 元 455.76 ms
treatment（新版） 6,024 35.89% 10.06% 7.61 元 499.28 ms
差异与检验 SRM p=0.66 +3.19pp +1.31pp (p=0.0141) +0.84 元 +43.52 ms (p<0.001)
  • 主指标显著为正：转化率从 8.75% 提升至 10.06%（绝对提升 +1.31 个百分点，相对提升 +14.9%），卡方检验 p = 0.0141 < 0.05。
  • 已转化客单价持平（P-3.6）：对照组 77.38 元 vs 实验组 75.67 元（p = 0.3986），说明 ARPU 提升来自“更多人下单”，而非单笔买得更贵。
  • 护栏指标显著变慢（P-3.4）：新版评价卡片引入更多图文元素，平均加载耗时增加 +43.52 ms（Welch t 检验 p = 7.68e-147）。

第四步：新老客异质性拆解（P-3.5）

如果只看总体数字就匆忙全量上线，会错过本项目最关键的业务洞察！按 is_new_user 拆开一看：

用户类型 对照组转化率 实验组转化率 绝对提升 卡方 p 值 结论
老客 (0) 10.66% 10.48% −0.19pp 0.8235 无显著变化
新客 (1) 7.22% 9.71% +2.49pp 0.00027 高度显著提升

业务解读：老客已经熟悉店铺与口碑，新版评价卡片并未提升其下单意愿，反而白白多承受了 +43.5ms 的页面加载延迟；而新客对陌生商品缺乏信任，强化评价卡片直接把新客转化率拉升了 +2.49 个百分点！

“总体 p=0.014 < 0.05，建议立即 100% 全量推给所有用户”

忽视了护栏指标变慢和老客零收益的事实，让近一半老客平白承受更慢的页面加载。

“优先对新客定向放量，同时请研发优化评价卡片懒加载后再评估老客全量”

兼顾了显著收益、性能护栏与人群异质性，是真实业务中最受欢迎的落地建议。

多重检验与上线纪律 实验结束后，分析师把数据按 20 个不同城市切片逐一算 p 值，终于发现“某三线城市 p = 0.04”，于是宣称实验只在该城市有效。这犯了什么统计错误？

事前基于业务机理假设的新老客分层与事后漫无目的地刷几十个切片完全不同；前者可指导灰度，后者极易过拟合噪音。

练习：补充项目三的长期观察限制

14 天短期实验通过后，还有哪些长期风险需要上线后继续追踪？

参考答案
  1. 新奇效应（Novelty Effect）：新卡片刚上线时新鲜感可能短期拉高点击，需在放量后继续观察 2～4 周转化率是否回落。
  2. 售后退款率与长期复购：如果新版评价卡片过度筛选好评导致预期落差，可能推高后续退款率，需补充售后与复购护栏。
  3. 低端 Android 机型 P95 耗时：平均只慢 43.5ms，但需核查最慢 5% 用户的 P95 加载延迟是否导致跳失。
