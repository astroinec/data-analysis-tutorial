File / Folder 文件/文件夹 文件装内容，文件夹组织文件；目录是文件夹的另一说法 电脑基础
Extension 扩展名 文件名最后的类型后缀，如.csv、.ipynb；改名字不等于转换格式 扩展名
Path 路径 告诉电脑文件在哪里的地址，不是互联网网址 路径
Absolute path 绝对路径 从盘符或根目录出发的完整位置 路径
Relative path 相对路径 从当前目录出发，..表示上一级 路径
Working directory 当前工作目录 程序查找相对路径时的出发点，不一定是你想的文件夹 Jupyter
Terminal / Prompt 终端/命令提示窗口 输入系统命令的地方；本课用Anaconda Prompt，不是Notebook代码格 电脑基础
Command 命令 让终端执行的操作，如激活环境；提示符不是命令的一部分 安装
Interpreter 解释器 真正执行Python代码的程序；电脑可能有多个 环境体检
Environment 环境 给项目单独准备的Python及包组合，避免互相影响 Anaconda
base 默认基础环境 Anaconda自带的管理环境，本课不往这里装课程包 Anaconda
conda 环境管理工具 创建、激活独立环境；本课统一da-course 安装
pip Python包安装工具 通过当前Python安装包，本课用 python -m pip 安装
Package / Library 包/库 别人写好的工具集合，如pandas；不是压缩包同义词 环境体检
Dependency 依赖 项目运行必须具备的其他包及版本 环境体检
Kernel 内核 Notebook背后实际跑代码的Python进程，选错可能缺包 Jupyter
Cell 单元格 Notebook中的一个代码或说明块，执行顺序影响变量 Jupyter
Markdown 轻量标记文本 用标题、列表、表格编写说明，不当Python执行 Jupyter
Traceback 错误追踪 报错时显示的执行路径；先看最后的错误名与原因 报错表
Encoding / UTF-8 / GBK 编码 文字如何存成字节；读错会乱码或解码报错 读取数据
BOM 字节顺序标记 UTF-8-sig带的文件头，常帮助Excel识别中文；不是数据列 数据集

二、Python基础

英文 中文 白话解释 去哪里学
Variable 变量 给一个值起名字，值可变；price=39是赋值 变量
Type 数据类型 值属于整数、浮点数、文本等哪一类 变量
int / float 整数/浮点数 int无小数，float表示小数但可能有二进制精度误差 类型
str / String 字符串 文本，'39'不是数字39 类型
bool / Boolean 布尔值 True或False，表示判断结果 类型
None 空对象 Python中表示没有值；与数字0、空字符串不同 类型
List 列表 一串有顺序的值，位置从0开始 列表
Dictionary / dict 字典 按键查值，像“指标名→指标值”的小账本 字典
Key / Value 键/值 字典中的名称与对应内容；列名也常起查找作用 字典
Condition 条件 能判断真假的表达式，不是文字解释 条件
Loop 循环 对一批元素重复执行代码；pandas表格常可直接整列处理 循环
Function 函数 带输入、完成操作、可返回输出的一段代码 函数
Argument / Parameter 实参/参数 定义时的输入名字与调用时传入的具体值 函数
Return 返回 将计算值交给调用者，与只显示的print不同 函数
Import 导入 把包或模块工具引入当前Python会话 环境与包
Indentation 缩进 空格决定代码层级；Python不是装饰性排版 控制结构
Ellipsis / ... 省略号占位值 练习的未作答标记，不是随便可算的数字 Jupyter

三、表格与pandas

英文 中文 白话解释 去哪里学
DataFrame 二维表格 有行有列的pandas对象，像可编程的工作表 认识表格
Series 一维序列 带标签的一列值，不等于一列DataFrame 认识表格
Row / Column 行/列 行常表示记录，列常表示字段；左边索引不默认算数据列 认识表格
Field 字段 一类信息的名称，如订单号、实付金额 数据字典
Index 索引/行标签 pandas最左边的行标签，不一定连续，也不必从0开始 筛选
Position 位置 第几个，从0开始，区别于行标签 筛选
loc / iloc 按标签/按位置选择 loc找标签，iloc找位置；不是两种可任意混用的拼写 筛选
Shape 形状 (行数,列数)，不包含索引和CSV表头 表格
Filter / Mask 筛选/布尔掩码 每行一项True/False，只保留满足条件的行 筛选
Sort 排序 按某列升降序排列，不自动改变业务含义 排序
Copy 副本 留下原材料再操作；不等于另导出文件 筛选
Groupby 分组 把同类记录放一起再计算，如按平台统计 分组
Aggregate / agg 聚合 多条记录汇成一个数或一行，如求和、计数、均值 分组
sum / mean 总和/平均值 求总量或普通算术平均；mean不自动按数量加权 分组
count / size / nunique 非空计数/行数/不同值数 三种计数分母不同，数订单常用唯一订单号 分组
Merge / Join 合并/连接 按共同键给订单补商品或客户信息，不是把文件上下堆起来 合并
Primary key 主键 唯一标识每条实体，如order_id，不拿客户复购当主键重复 合并
Foreign key 外键 指向另表的编号，如订单里的product_id 合并
many-to-one 多对一 多笔订单指向一个商品；右表同键必须只有一行 项目检查
Left join 左连接 保留左表所有行，右表无匹配时补缺失；可能仍因右键重复增行 合并
Inner join 内连接 只保留匹配上的记录，可能丢订单 合并
Validation 验证 主动检查键关系、行数、集合和匹配，不是“没报错就对” 项目
Pivot table 数据透视表 把分类摆到行列并聚合；默认mean不等于销售总和 透视
CSV 逗号分隔文本 表格的一种文本保存方式，有编码、分隔符与表头 读取
Excel workbook / Sheet 工作簿/工作表 一个.xlsx可有多张表；读取时指定sheet_name 读取

四、清洗与质量

英文 中文 白话解释 去哪里学
Missing value / NaN / NA 缺失值 没有记录，不是零；未评价不等于差评 缺失
Duplicate 重复 整行重复或主键重复要分别核查；同客户多单可合法 重复
Data cleaning 数据清洗 按规则处理可确认的格式与质量问题，不是把“不好看”的值删掉 清洗
Outlier 离群值 在统计分布上较远的值，不自动等于错误 异常
Anomaly 异常 违反业务或质量规则的记录，如数量为负 异常
Type conversion 类型转换 把文本变数字或日期；失败需保留并核查 类型
Coerce 失败转缺失 errors='coerce'使无法解析的项变缺失，不代表已经清洗正确 类型
Parse 解析 按格式理解文本，比如将日期字符串读成日期 日期
Standardization 口径/写法统一 统一平台别名与空格等；不能随意把不同类别混为一类 文本
Imputation 缺失填补 根据可说明的依据补值；本批不把均值填补当万能默认 缺失
Reconciliation 对账 比较明细与分组总和、状态和等，找漏算与重复计算 项目
Reproducibility 可复现 同份输入、明确环境与步骤，别人能重做结果 项目

五、图表与阅读

英文 中文 白话解释 去哪里学
Visualization 可视化 用图呈现数据结构与问题，不只追求好看 选图
Figure / Axes 整张画布/坐标图区域 fig是画布，ax是具体绘图区域，不是数据表 matplotlib
Axis 坐标轴 表示横纵方向的量或类别，需标单位 matplotlib
Bar chart 柱状/条形图 比较类别大小，柱轴从0起更诚实 选图
Line chart 折线图 展示有序时间趋势，先按时间排序 选图
Scatter plot 散点图 每点一条观察，看两变量关联，不自动证明因果 seaborn
Histogram 直方图 按数值区间看分布，与按类别的柱图不同 seaborn
Boxplot 箱线图 展示中位数、四分位及统计离群标记，不能自动判断业务错值 seaborn
Distribution 分布 值集中在哪、是否偏斜、离散有多大 seaborn
Median / Quantile 中位数/分位数 排序后的中间或某比例位置，常比均值更能抵抗极端值 seaborn
Hue / Legend 颜色分组/图例 用颜色区分类别，并说明每种颜色是什么 seaborn
Hover 悬停提示 鼠标移到图上显示数值；不替代清楚的标题 Plotly
Renderer 渲染方式 决定Plotly如何显示，不改变数据本身 Plotly
CDN 内容分发网络 从外网加载脚本，断网可能失效；离线图要内嵌资源 Plotly
Correlation / Causation 相关/因果 一起变化不等于一方造成另一方，需额外设计和证据 项目边界

六、业务分析与来源

英文 中文 白话解释 去哪里学
Granularity 粒度 一行是什么；本项目一单一种商品，真实订单也可能一单多行 数据字典
Metric 指标 具有明确计算公式、筛选、期间和单位的业务数字 项目
Metric definition 指标口径 规定统计谁、何时、按什么状态、怎么算 项目
GMV 商品交易总额 常见定义各异，必须明确是否含退款及所用status过滤 项目
Completed net sales 已完成净销售额 本项目只加已完成支付，业务口径，不是财务确认收入 项目
AOV 客单价 已完成金额/已完成唯一订单数，不是每件商品均价 项目
Refund rate 订单退款率 退款订单数/同范围全部订单数，不是退款金额比 项目
Buyer 购买客户 本窗口有已完成购买的人；注册未购不算 项目
Repeat purchase rate 窗口复购率 本窗口至少2笔已完成订单客户/本窗口购买客户，非终身忠诚 项目
Channel / Platform 获客来源/交易平台 从哪认识店与在哪下单是不同维度 数据字典
Contribution share 贡献份额 品类金额/总金额，分子分母要同状态与期间 项目
Gross profit estimate 商品毛利估算 已完成金额减静态成本×件数，未计全部费用 项目
Net profit 净利润 扣除相关成本费用后的财务概念；本数据不足以计算 项目限制
Achievement rate 目标达成率 同期间实际/目标，全年不是月比率简单平均 项目
MoM / YoY 环比/同比 比上一期/上年同期；本包无2024订单不能同比 项目
Percentage point 百分点 10%到12%增加2个百分点，而不是增加2% 项目
Observation window 观察窗口 允许看数据的期间，新客晚来可观察时间更短 项目
Synthetic data 模拟数据 按规则生成的虚构记录，规律不是真实因果发现 来源
Public data 公开数据 可以公开访问，不自动等于可任意商用转载 来源许可
License / CC0 许可证/公共领域贡献声明 具体授权范围要查证；企鹅数据CC0不自动覆盖网站图片 来源许可
Data dictionary 数据字典 逐列说明含义、单位、缺失、取值及关联 字段说明

七、统计推断、SQL 与方法论术语

英文 中文 白话定位 去哪里学
SQL 结构化查询语言 从数据库按规则取数、聚合、连接与窗口排名 SQL 基础 · 连接与窗口
Funnel / Conversion 漏斗/转化 按唯一用户去重统计各步骤人数与环节转化率 漏斗与留存 · 项目二
Retention / Cohort 留存/同期群 在完整观察窗口下按注册批次比较 D1/D7/D30 留存 漏斗与留存 · 项目二
A/B test A/B 测试 随机分流对照实验，需校验 SRM、主指标、护栏与人群异质性 假设检验 · 项目三
Hypothesis test 假设检验 用卡方检验或 Welch t 检验判断差异是否与随机波动相容 假设检验
ROI 投资回报指标 要明确收益、成本与时间口径；缺成本字段时不可强行计算 指标体系
RFM 最近消费、频次、金额分层 用中位数阈值划分八类客户（注意 R 越小越近） RFM 分层
