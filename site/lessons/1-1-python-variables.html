1-1变量与数据类型

用图书价格和一笔折扣订单，分清名字、数字、文字与判断结果。

  • 约 50 分钟
  • 难度 ★☆☆
  • 配套练习本 notebooks/1-1_python_variables.ipynb
  • 前置：已完成第 0-6 课，能在原位置打开 Notebook 并运行代码格

学完后你能做到

  • 给书名、单价、数量起名字，解释赋值符号 =。
  • 区分 int、float、str、bool，不把价格写成文字。
  • 算两本书的价格，解释 discount=0.1 为什么是减去 10%。
  • 在练习本完成 4 道独立练习，并看到中文检查结果。

先把操作位置放对

打开 本课练习本，选择 Python (da-course) 内核。所有标为 Python 的代码都在 Notebook 代码格运行，不是在 Anaconda Prompt 输入。先按从上到下的顺序运行示范，再填练习中的 ...。如果你重启内核，电脑会忘记之前的名字；要重新运行前面的格子，而不是反复点击最后一格。

本课用随包 books.csv 的前三条虚构图书记录和文创店的一笔模拟订单，不代表真实书籍、作者或企业。为了先学语言，本页把核验过的少量值直接写进代码。练习本顶部已帮你载入同一数据，第 2-1 课才详细拆解读文件。你现在不需要背那段准备代码。

1. 变量是贴在值上的名字

给资料贴便签

你写分析报告时会把某个数记作“本月订单数”。变量也是名字：price 是便签，88.9 是它现在指向的内容。变量不是永远锁死的抽屉，重新赋值后名字可以指向新内容。

title = "月光与我"
price = 88.9
quantity = 2
print(title)
print(price * quantity)

输入是第一本图书的书名、每本 88.9 元和购买 2 本。前三行分别给值命名，最后两行让结果显示出来。输出为：

月光与我
177.8

= 的意思是“把右边算好的值交给左边这个名字”，不是数学上的两边恒等。Python 先算右边，再改左边。名字尽量用英文小写，多个词用下划线连接，如 total_price。不能有空格、不能以数字开头；Price 与 price 是两个名字。引号、括号、等号使用英文半角，中文说明放在引号里。

quantity = 2
quantity = quantity + 1
print(quantity)

输入数量 2，第二行先算旧数量加 1，再把 3 交回 quantity，所以输出 3。原来的书价没有跟着变化。Notebook 中只有最后一行表达式会自动显示；想观察多项内容时，用 print(...) 更明确。变量赋值本身通常不显示输出，不代表没有执行。

2. 四种够用的数据类型

整数 int

quantity = 2：没有小数点，适合本数、行数。不要写成 "2"。

小数 float

price = 88.9：有小数点，适合金额、比例。0.1 是十分之一。

字符串 str

title = "月光与我"：引号包住的文字。看起来像数字的 "88.9" 仍是文字。

布尔 bool

is_recent = True：判断结果只有 True 或 False。首字母大写，不加引号。

print(type(2))
print(type(88.9))
print(type("88.9"))
print(type(True))

输入四个值，type 查看它们的类别。输出依次是 <class 'int'>、<class 'float'>、<class 'str'>、<class 'bool'>。尖括号是 Python 显示类型的样子，不是需要复制的代码。现在只要能回答“为什么第三个不能直接当价格算”，就掌握了核心。

看起来像加法，其实拼接文字

print("88.9" + "2")
输入两段文字，+ 把文字连接，实际输出 88.92，不是购买两本的金额。

先用数字表示价格，再乘数量

print(88.9 * 2)
输入单价与本数，* 做乘法，输出 177.8。

字符串中的中文可以正常显示。单引号 '月光与我' 和双引号 "月光与我" 都可用，但开头结尾要成对。不要把字符串本身、变量名、屏幕输出混淆：print(title) 找名字的内容，print("title") 只会输出字母 title。

3. 运算和百分比：先说清单位

常用运算是 + 加、- 减、* 乘、/ 除。括号表示先算括号里的内容。金额和比例要分开：10 表示数值十；0.1 表示十分之一。百分号 % 在 Python 中是取余运算，不是写百分比的符号；十个百分点用 10 / 100 或 0.1。

下面取随包订单 SG25000039：2025-01-02，单价 22 元、5 件、优惠比例 0.1，原字段实付金额 99 元。

unit_price = 22.0
quantity = 5
discount = 0.1
original_amount = unit_price * quantity
pay_amount = original_amount * (1 - discount)
print(original_amount)
print(pay_amount)

输入是这笔订单的三项数据。先算原价 22×5=110，再保留原价的 90%，输出 110.0 和 99.0。这不是“一折”：discount 存的是减免比例，0.1 是减 10%，即付九折价；减 20% 写 0.2，付八折价。不是所有数据文件都这样命名，所以工作中要读字段说明。

print(0.1 * 100)
print(99 / 110)

输入优惠比例和实付/原价，分别换算成百分数数值、保留比例，输出 10.0 和 0.9。报告若写“优惠 10%”，单位 % 是报告文字；计算时仍用 0.1。小数计算偶尔出现很长的尾巴是浮点表示现象，不要急着逐行改数据。后面展示金额可以 round(pay_amount, 2)：输入金额，四舍五入保留两位，结果仍是数字。

4. 判断结果也能有名字

year = 2021
is_recent = year >= 2020
print(is_recent)
print(year == 2020)

输入第三本书的出版年份 2021。>= 问“是否至少 2020”，输出 True；== 问“是否恰好 2020”，输出 False。这里“新书”仅是练习约定，并不代表行业统一标准。>、<、<=、!= 分别是大于、小于、小于等于、不等于。一个等号赋值，两个等号比较。

discount = 0.1 在本数据里表示什么？

比例和金额不是同一单位；公式是原价乘以 (1 - discount)。

5. 四道练习：先独立写，再检查

在本课 Notebook 中替换每题的 result = ...。不要把省略号连同整行删掉，也不要改检查编号。每题独立使用已准备好的原始数据，不要求你先完成上一题。

1-1.1 保存书名

把第一本书的书名“月光与我”赋给 result，保持字符串类型。提示：中文文字要有成对引号。

参考答案与观察

result = "月光与我"
输入书名文字，赋值不产生可见输出；检查通过表示文字与类型符合题意。

1-1.2 计算两本书金额

第一本书单价 88.9 元，买 2 本。把总价赋给 result，不要直接填写带“元”的文字。提示：单价乘数量。

参考答案与观察

result = 88.9 * 2
输入单价和数量，输出观察可用 print(result)，应为 177.8。

1-1.3 计算判断结果

第三本书年份是 2021。把“出版年份至少是 2020”这个判断赋给 result，不要写 "True"。

参考答案与观察

result = 2021 >= 2020
输入年份和边界，比较得到布尔值 True。字符串 True 不能代替判断结果。

1-1.4 还原订单优惠

单价 22 元、5 件、减免比例 0.1。把折后金额赋给 result，不依赖前面题目的 result。

参考答案与观察

result = 22.0 * 5 * (1 - 0.1)
输入三项数据，先算括号再乘，实际金额 99.0 元，与订单字段一致。

常见报错：先看最后一行

现象 白话原因 纠正路线
NameError: name 'price' is not defined 这个内核还没收到 price 的赋值 检查拼写、大小写，先运行赋值格
TypeError，数字和文字不能相加 "88.9" 被当作文字 本课直接用数字 88.9；数据列转换后面学
SyntaxError 引号未闭合或用了全角符号 把标点切成英文半角，一对对检查
有输出但结果是 88.92 两段字符串被拼接 看 type，不要只看屏幕像不像数字

报错不是“电脑不适合学习”。每次只改一个可能原因，再运行该格。Notebook 的旧输出不会因你修改代码自动更新，要再次执行才能确认新结果。

求职中的用法

运营和编辑岗位常需要解释“单价×数量×折扣”与“优惠比例”。面试时能说清输入、公式、单位，比只背变量类型更有用。这里可描述你练习了模拟订单金额核对，不写成真实企业降本业绩。
