0-1数据分析是什么？文科生的优势与学习路线

把一个模糊业务问题变成可回答的问题，知道文科背景能贡献什么，读懂这门课程的边界。

  • 约 20 分钟
  • 难度 ★☆☆
  • 前置：无需编程知识；准备一张纸或一个能记笔记的文档。

本课完成后，你能做什么

  • 用“问题 → 数据 → 整理 → 比较 → 表达”描述一次分析，而不是把“会用软件”当成全部。
  • 给一个指标说明统计对象、时间范围和计算方法。
  • 分清事实、解释、建议，并指出一个结论不能支持的推断。
  • 找到本教程的准备课、练习本、答案本和求助工具箱。

1. 你不是从零开始思考，只是从零开始使用工具

数据分析是用记录回答问题，并把回答讲给需要做决定的人听。Python 是工具，pandas 是处理表格的工具箱，图表是表达手段；都不是分析的目的。文科训练中的阅读、论证、访谈、归纳和写作可以帮助你识别概念含混、理解受众、区分证据与主张，但仍需补上指标、计算和检验。不会数学公式不意味着不能入门，也不意味着数字可以跳过核验。

一份可核查的调查报告

写读书报告不能只摘一句话就声称理解全书；分析订单也不能只看最高一天就声称“全年销售很好”。两者都需要问题、材料范围、证据和限制。程序替你重复计算，你仍对问题是否问对、解释是否越界负责。

2. 用四行小表走完一次分析

假设你在一家虚构文创店练习，想知道“哪个渠道带来的订单更多”。先确定：只统计下面这份样本，每行代表一笔订单，同一订单只出现一次，不把它冒充全年结果。

订单号 渠道 实付金额（元）
O01 搜索 80
O02 社群 40
O03 搜索 20
O04 社群 60

先不用代码，用手算：搜索 2 笔，社群 2 笔；两个渠道都是 100 元。订单数相同、样本销售额相同，不代表成本相同、利润相同或顾客满意度相同。 数据没给成本、退款和评价，不能替数据编造。

层次 可以写的句子 依据或限制
事实 这四笔样本中，搜索与社群各有两笔订单。 逐行计数，可复核
解释假设 社群可能更有利于复购。 还需要用户与复购记录，当前未证实
下一步 补充各渠道投入、退款与复购信息后再比较。 指明要新增的证据
越界结论 以后应该把所有预算都投给社群。 当前数据不支持
  1. 问题：比较什么，谁会据此做决定？
  2. 数据：一行是什么、来自哪里、包含哪段时间？
  3. 整理：重复、缺失、金额格式是否会影响比较？
  4. 计算：先分组，再按相同口径汇总。
  5. 表达：结论 + 证据 + 限制 + 下一步，而不是只发一张图。

指标需要“口径”，不是只有名字

“销量”可能指件数，也可能被人误当订单数。“销售额”可能含运费、折扣或退款。一个可执行定义应写成：“样本中唯一订单号的数量；时间为指定自然月；排除取消订单。”如果数据没有取消状态，就说明无法执行这一排除规则，而不是悄悄假设全部有效。

本课程 P-1 使用虚构经营记录；公开数据部分是历史教学材料。你能得到的是练习作品与可复现的方法，不是对真实企业的评价，也不是凭空产生的简历业绩。

3. 这门课学什么，暂时不学什么

文件路径、安装 Anaconda、独立环境、环境体检、JupyterLab。没有通过环境检查，先排错，不急着敲复杂代码。

阶段 1～3：够用的 Python 与表格

变量、列表与字典、基本控制流程；读取、筛选、分组、合并；辨别缺失、重复、日期与异常。每课带独立练习。

阶段 4 与 P-1：把结果讲出来

根据问题选图、设置中文字体、交互图；完成线上文创店销售分析，写出证据与限制。

阶段 5～8：后续路线

统计、SQL、分析方法与求职冲刺目前是路线预告，不是已完成教材。先把当前课程与项目做扎实。

准备课中有些按钮和窗口以 HTML 示意呈现，它们不是实机截图，也不是可安装的软件。网页上的小交互只模拟几行数据，不执行 Python、不读取电脑。真正 Python 练习在 notebooks/；对应参考答案在 solutions/。建议先做自己的练习，再比较答案，不要同时混用两份 Notebook。

4. 怎样学才不被代码吓住

每课先读目标，再看最小示例；运行后描述“我看到什么”，然后只改一个地方，预测结果再运行。代码失败时把最后一行错误和相关代码保留下来。不是“我不适合”，而是“目前有一个可定位的问题”。

不要把“运行成功”与“分析正确”画等号：程序可以成功计算一个含重复记录的错误合计。因此验收包含两类：工具是否正常、结果是否能解释。卡住时用环境排查或常见报错，不要随机卸载软件。

对求职有用的不是装了多少软件

练习把成果讲成：“为了回答某问题，我使用某范围的数据，按某口径处理，再用某证据得到有限结论。”没有真实实习成果时，可以诚实写“虚构数据练习项目”；不要写“为公司提升收入 30%”。作品的价值在于方法可核查、图表能读、限制说清楚。

5. 理解检查：先不打开 Python

练习 1：写清口径

把“哪个渠道最好”改成一个能用上面四行数据回答的问题。提示：只选择数据已有的数量或金额，并注明样本范围。

参考答案

“在上面四笔订单样本中，各渠道的订单数分别是多少？”也可以问实付金额合计。不能问利润最高，因为没有成本。

练习 2：用证据纠正越界

有人说“社群和搜索销售额一样，所以用户质量一样”。用两句话指出问题并提出补数建议。

参考答案

销售额相同只说明这份样本的金额合计相同，不能说明用户质量相同。若关心长期价值，需要用户标识、复购时间、退款及成本等数据，并事先定义“用户质量”。

下面哪句话更准确？

工具可以降低重复劳动，不能替你确认原始数据是否适合问题，也不能自动补齐缺少的证据。

练习 4：一句话作品说明

任选“图书”“活动报名”或“虚构订单”，写出问题、所需字段、计划输出各一项。提示：先追求具体，而不是复杂。

参考答案

问题：各类别图书数量有何差异？字段：唯一图书编号与类别。输出：按类别计数的表格与条形图，附数据来源和范围；缺失类别单独说明。
