0-6JupyterLab 上手

学会打开、编辑、运行、保存与重启练习本，理解代码格、输出和内核的区别。

  • 约 40 分钟
  • 难度 ★☆☆
  • 配套练习本 notebooks/0-6_jupyter_basics.ipynb
  • 前置：已完成环境体检；关键失败为 0；在课程根目录启动 JupyterLab。

本课目标

  • 在 JupyterLab 从原 notebooks 位置打开练习本，选择 Python (da-course)。
  • 分清 Markdown 格、Python 格、输入标记与输出；用 Shift+Enter 运行。
  • 解释执行顺序、保存与内存变量的区别，能重启内核后从头运行。
  • 完成三个独立练习，知道空白答案不等于系统出错。

1. 打开正确文件，先不新建一堆空白本

如果 Jupyter 已在运行，直接回浏览器，不重复启动。如果没有，在开始菜单打开 Anaconda Prompt，正常权限运行：

conda activate da-course
cd /d "D:\da-course\data-analysis-tutorial"
python -m jupyter lab

第一条路径换成自己的。浏览器没自动打开，就复制自己服务器日志的本机地址到浏览器地址栏；地址与 token 不发公开截图。Prompt 此时是服务器日志窗口，不再用来输入下一条普通命令。

浏览器左侧应显示课程根目录。双击 notebooks 文件夹，再双击 0-6_jupyter_basics.ipynb。练习本可从对应文件查看；运行时仍在完整教材原目录，不只把一份下载副本搬到桌面。

JupyterLab 编辑器（界面示意，不是实机截图）
区域 内容示意 用途
左侧文件栏 data / notebooks / solutions 打开原始练习本；名字相同不代表路径相同

菜单与工具栏 File / Run / Kernel / 保存图标 保存、运行、切换或重启内核

菜单文案可随 JupyterLab 版本和语言变动；目标是找到“Run/运行”和“Kernel/内核”。如果名称不确定，可先鼠标悬停查看提示，不随机删除文件或重启整台电脑。

2. 两种格子：说明不是代码，代码不是终端命令

Markdown 格放课程说明，可写段落、标题、表格。双击进入文字编辑，按 Shift+Enter 渲染回可读页面。

Code/Python 格放 Python。点击后可编辑；按 Shift+Enter 运行并移动到下一个格。Ctrl+Enter 通常运行并留在当前格。最初先只掌握 Shift+Enter，不用背全套快捷键。

错窗口

在 Python 格写 conda activate da-course 或 cd /d ... 会得到 Python 语法错误。在 Prompt 写 print("你好") 也不是课程的正确窗口。

本课写 Python

print("你好，数据分析")
选中代码格，按 Shift+Enter，观察下面输出，而不是把它粘到 Anaconda Prompt。

你好，数据分析

print 明确打印文字。字符串要有英文引号，中文内容可以在引号里面。下一阶段会细讲语法，当前先确认你能输入、执行、看到结果。

有的正常代码不产生输出

sample_total = 12

这一格只是把值保存在变量里，所以没有输出是正常的。运行序号从 [ ] 变成数字，说明它执行过；想看内容，再运行 print(sample_total)。Notebook 常自动展示代码格最后一个表达式的值：

2 + 3

输出是 5。把两行表达式写在同一格，不保证每行自动显示；要逐个显示就用 print 或 display。代码格下方的输出不能通过修改输出文字改变计算结果，得改代码再运行。

左侧标记 意味着什么 你的下一步
[ ] 当前格未在此内核执行过 选中格，Shift+Enter
[*] 正在执行或等输入 等实际运行完成；若长时间无变化，看代码与内核状态
[3] 它是这次内核中的第 3 次执行 序号不是固定行号；乱序执行时数字会乱
红色错误堆栈 执行遇到错误 看最后一行类型，再定位相关代码，不自动忽略

如果 [*] 长时间不结束，先确认有没有 input() 等待输入，或你是否运行了较重任务；本课小样例应很快完成。可用 Kernel → Interrupt Kernel 中断当前本子的内核。中断不删除文件。不要把 CPU 占用作为理由强制结束所有 Python 进程，因为可能有其他工作。

3. 执行顺序：屏幕上的上下顺序与实际运行顺序可以不同

下面是解释示例，不依赖你先前格子：

value = 10
value = 20
print(value)

结果为 20，因为后一次赋值覆盖了内存中旧值。你若只改上方代码但没重新运行，内存还是旧结果。看上去文字正确、图表却不变，常是运行顺序问题，不一定包有故障。

纸上菜谱与正在做的锅

Notebook 文件是菜谱；内核内存是锅里当前状态。保存菜谱不会重新下锅，重启内核会倒掉当前状态但保留已保存菜谱。完整从头运行才说明菜谱能复现。

因此写完一份练习，先保存，再按 Kernel 菜单重启内核，然后从第一格到最后一格运行。也可使用“Restart Kernel and Run All Cells/重启内核并运行所有单元格”相应菜单，确认目标是当前练习本。不要把“Run All”作为空白学生练习必须全绿的要求：... 还没填时，检查器显示“还没作答”是设计行为。

4. 第一初始化格要运行，不能把环境路径当题目答案

每份课程练习本从初始化格开始：

import sys
sys.path.insert(0, "..")
from dacheck import check, hint, setup_chinese_font
import pandas as pd

这里 .. 帮 Python 找到上一层的课程工具。它不代表更换系统 PATH，也不把电脑配置永久修改。第一格只在整套教材 notebooks 或 solutions 原位置运行才符合约定。下一阶段还会学习 import，现在先运行且观察是否有错误。

如果报 No module named dacheck，先检查你是否只搬走了本子，以及左侧当前文件的完整路径；不去网络安装同名包。报 pandas 缺失时看实际内核 sys.executable，回环境体检；不要在任何随机 Notebook 里重复装包。

字体示范采用课程工具：

font_name = setup_chinese_font(verbose=True)
print("当前候选字体：", font_name)

正常会报告选中的中文字体。None 或缺字警告说明需要去A-2 字体问题，不保证一切字体正常。文字练习可以先继续，图表前要解决。后续图表写 plt.show() 显式显示，不能靠屏蔽字体警告过关。

5. 三个独立练习：把 ... 替换，不改 check 编号

在 0-6_jupyter_basics.ipynb 中，每题的变量先赋 ...。这是一个占位对象，提醒你尚未作答，不是代码错误，也不是要填一个“省略号字符串”。把省略号替换为表达式或值，保留左侧变量名和下面 check(...)，再运行当前格。

练习 1：让结果可见

给 result 赋值为 2 + 3，运行格子。检查器应显示“通过”。再试用 print(result) 观察数值。

参考答案

result = 2 + 3
check("0-6.1", result)
数值是 5。这题不用前一题变量；即使后两题空白也能独立检查。

练习 2：保存一段中文文字

给 message 赋值为字符串 "我能运行代码"，英文引号保留。提示：引号里面是文字，引号外是 Python 语法。

参考答案

message = "我能运行代码"
check("0-6.2", message)
不要把英文双引号改成输入法的弯引号。中文内容本身不需要转成英文。

练习 3：给表格数行

用 pd.DataFrame({"任务": ["读取", "检查", "保存"]}).shape[0] 给 task_rows 赋值，再检查。暂不要求记住整套 DataFrame 语法，先观察“三项任务对应三行”。

参考答案

task_rows = pd.DataFrame({"任务": ["读取", "检查", "保存"]}).shape[0]
check("0-6.3", task_rows)
结果为 3；检查器从同一小样本动态计算，题目不依赖别的题目变量。Python 表格操作在阶段 2 系统学习。

文件与内存不同。重启后变量清空，必须从头运行初始化与相关代码。

6. 保存、备份、退出：各做各的事

按 Ctrl+S 或点击保存图标，确认标签中的未保存标记消失。需要保留原始练习模板时，可先用 File → Save Notebook As 以新名保存在同一个 notebooks 文件夹，避免破坏相对路径。不要把副本另存到 ZIP 内、安装目录或单独桌面位置。

保存可能包含输出：生成的表格、图片、错误与路径。分享作品之前查看是否含用户名、敏感记录或浏览器 token。项目原数据保留不覆盖；导出成果另用新文件名。

退出顺序：

  1. 保存正在编辑的 Notebook。
  2. 在 JupyterLab 关闭对应内核/会话或确认不再需要运行。
  3. 回 Jupyter 服务器所在 Prompt，按 Ctrl+C，按该窗口提示确认停止服务器。
  4. 浏览器标签可关闭。仅关浏览器不保证服务器已停止；不要关掉服务器后把浏览器报连接失败误认为课程坏了。

常见问题与恢复动作

症状 常见原因 最小恢复动作
按运行后文字变成标题，没有执行 Markdown 格 把类型改成 Code，或新建代码格再输入 Python
一格无输出但序号变数字 仅赋值、注释或 import 用 print/最后表达式显示，不重复安装
NameError: name ... is not defined 初始化未运行、错拼或重启后内存清空 从第一格按顺序运行，查看拼写
改代码但图没变 未重新执行、看错旧输出 运行正确格子；必要时重启并从头运行
一直显示星号 执行未结束/在等输入 看当前代码，Interrupt 当前内核，勿杀所有进程
“还没作答” 仍有 ... 填当前题，不把它当安装失败
文件栏不是课程目录 服务器启动位置不对 保存、正常关闭，从课程根目录重启

作品应该能“重启后从头跑”

面试演示最怕只有内存里的旧变量能救场。完成项目后，保存并重启从头跑一遍，比截图上一张漂亮图更能证明可复现。空白练习本不要求全通过，但自己的完成版应没有被忽略的错误。
