7-3RFM 用户分层

掌握经典的 RFM（最近消费、频次、金额）客户分层模型，用中位数阈值把 2427 位购买客户划分为八类并制定差异化策略。

  • 约 60 分钟
  • 难度 ★★☆
  • 配套练习本 notebooks/7-3_method_rfm.ipynb
  • 前置：已完成第 7-1 与 7-2 课，熟悉 groupby 聚合与日期差计算

本课可验证目标

  • 准确定义 R（Recency）、F（Frequency）、M（Monetary）三个维度的计算口径与基准日。
  • 牢记 R 越小越好（最近刚买过），避免把 R 的高低方向打反。
  • 用中位数作为客观阈值，把文创店 2427 位购买客户映射到八类经典分层。
  • 计算“重要价值客户”的人数占比与金额占比，并说出 RFM 模型的适用边界。

打开 7-3 练习本，选择 Python (da-course) 内核。本课使用 2025 年已完成订单（data/shop/orders.csv），基准日设为 2026-01-01。

1. 什么是 RFM 模型？

给所有客户发同一张满减券往往既浪费预算、又打扰老客。RFM 模型只用订单表里最常见的三个行为指标，就能把客户清清楚楚分成不同价值层级：

R · Recency（最近一次消费距今）

基准日 - 最后一次已完成下单时间（天数）。R 越小越好：昨天刚买过的客户比半年前买过的客户活跃得多。

F · Frequency（消费频次）

观察窗口内的唯一已完成订单数。F 越大越好：代表客户粘性与复购习惯。

M · Monetary（消费金额）

观察窗口内的已完成实付金额总和。M 越大越好：代表客户对店铺的营收贡献。

在文创店 2427 位购买客户中，三项指标的中位数实测为：R = 50 天、F = 3 单、M = 376.20 元。为什么用中位数而不是均值做切分阈值？因为我们在 5-1 描述统计 学过，消费金额与频次明显右偏，均值会被极少数土豪客户拉高，导致大量活跃客户被误判为“低价值”。

2. 八类客户分层与对应运营动作

规定：R_high = (R <= 50)、F_high = (F >= 3)、M_high = (M >= 376.2)，组合出 8 类客户：

R（近不近） F（频不频） M（高不高） 分层名称 建议运营动作（待验证假设）
高（近） 高 高 重要价值客户 VIP 专属服务、新品优先体验、切忌过度打折伤品牌
低（远） 高 高 重要保持客户 曾经高频高额但近期沉默，定向提醒/回访防流失
高（近） 低 高 重要发展客户 刚买过且客单高但频次低，推送关联商品促复购
低（远） 低 高 重要挽留客户 大额一次性客户即将流失，用有针对性的召回券测试
高/低 高/低 低 一般价值/保持/发展/挽留 低成本自动化触达为主，控制营销投入产出比

实测结果呈现出鲜明的二八效应：重要价值客户仅 756 人（占购买客户的 31.15%），却贡献了 1,247,488.80 元（占总已完成净销售额的 69.91%）！

3. RFM 模型的适用边界

RFM 很好用，但绝不是万能钥匙： - 不适合低频耐用品（如买房、买车、大型家电）：几年才买一次，F 几乎全是 1。 - 不适合冷启动新客：刚注册未下单的 573 位客户没有 R/F/M，需要用注册渠道与浏览行为做新客激活。 - 不包含利润与退货率：高 M 但高退款率的客户并不等于高利润客户。

RFM 方向判断 基准日为 2026-01-01。客户 A 的 R = 5 天，客户 B 的 R = 180 天，整体中位数 R_med = 50 天。谁属于“R 高（近期活跃）”？

R 是反向指标（越小越好），代码里务必写成 R <= R_med，千万别顺手写成 R >= R_med。

参考答案
done_ex = orders.loc[orders["status"].eq("已完成")]
rfm_ex = done_ex.groupby("customer_id", as_index=False).agg(
    last_time=("order_time", "max"), F=("order_id", "nunique"), M=("pay_amount", "sum"))
rfm_ex["R"] = (pd.Timestamp("2026-01-01") - rfm_ex["last_time"]).dt.days
