你已经有的能力

理解语境、找资料、组织论证、写清楚话。这些在分析中都用得上。要补的是把判断变成可检验的证据，而不是放弃自己的专业。

这份教程补什么

表格思维、够用的代码、指标口径、图表表达与可复现流程。不要求先学高等数学，也不假装学完第一批就懂所有统计。

怎么用这份教程

  1. 第一次：完整解压，再打开网页

    把教程 ZIP 全部解压到一个你有写权限的文件夹。不要在压缩软件内部运行。双击 site/index.html，用 Edge、Chrome 等现代浏览器阅读。只下载一个 HTML 文件，会丢掉图片、样式和交互。

  2. 每课：读 → 预测 → 操作 → 解释

    先看目标和小样例，猜一猜结果，再打开本课练习本运行。做完后用自己的话说出“这一步对哪些数据做了什么”。只复制代码并点运行，不等于已经会了。

  3. 做题：先自己试，再看提示和答案

    学生本在 notebooks/，同名答案在 solutions/。将 ... 换成答案，运行 check(...) 得到中文反馈；卡住时运行 hint(...)。不要把单个 Notebook 移出这两个文件夹。

  4. 留下证据：保存本子和学习记录

    按 Ctrl + S 保存 Notebook。网页“已学完”和勾选清单只保存在当前浏览器；练习检查进度存在本地文件。两者不自动同步，也不上传服务器。

关于本地网页进度

部分浏览器对直接打开的 file:// 页面采用独立存储，换页面、换浏览器、无痕模式或清理数据后，进度可能不共享或不保留。它只是辅助，不是学习成果的唯一记录。

如果你已经装好环境，想让所有页面稳定共用进度，可以在教程根目录的 Anaconda Prompt 中运行 python -m http.server 8000 --bind 127.0.0.1，然后打开 http://127.0.0.1:8000/site/。这个窗口保持打开；结束时按 Ctrl + C。不要绑定公网地址或分享这个端口。这一步可选，不是入门前置任务。
